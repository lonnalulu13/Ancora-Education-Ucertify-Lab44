## Objective of the Lab
In this lab, you will learn to manage New Technology File System (NTFS) permissions. NTFS permissions control access to NTFS files and folders. These permissions are cumulative, based on group memberships. The user gets the highest level of security from all the different groups they belong to. 
## Instructions 
### STEP 1 
On the taskbar, click the File Explorer icon to open the This PC window. 
### STEP 2 
In the This PC window, double-click Local Disk (C:) to open it. 
### STEP 3 
In the right pane, right-click Project and select Properties. 
### STEP 4 
In the Project Properties window, go to the Security tab, and under Group or user names, verify that CREATOR OWNER is selected, and then click Edit. 
### STEP 5 
In the Permissions for Project dialog box, under Group or user names, select Users (UCLIVELABS\Users). 
#### STEP 6 
Under Permissions for Users, check the Allow checkbox for the Full control permission, and then click OK twice. 
### Caution 
* You will observe that all the Allow checkboxes, which were not previously checked, get checked as soon as you check Allow for Full Control.
### STEP 7
Close all windows.
